Role Access

Admin access is limited to user administration: creating users, assigning the appropriate role/access, managing user accounts, and resetting user passwords.

Guide scope: This tutorial includes only the workflows applicable to this role/group. Features outside the assigned access are intentionally omitted or marked as permission-based.

1.Accessing the Application

  1. Open the application in a supported web browser.
  2. Enter your registered email address.
  3. Enter your password.
  4. Click Login.
  5. After successful authentication, the system opens the dashboard permitted for your role.

2.Admin Dashboard

The Admin Dashboard provides a User Overview and a Create New User panel. The overview shows the total number of users and role-wise user counts.

3.Create a User

  1. Enter the User Name.
  2. Select the appropriate Role/access.
  3. Enter the Login ID (email address).
  4. Enter the Password.
  5. Click Create.

The system validates required fields and displays a confirmation after successful creation.

4.User Management

  1. Open User Management from the left navigation.
  2. Search by name, email, or role.
  3. Review role, active status, created date, and last login.
  4. Use the available Actions to manage the selected user.

5.Reset Another User’s Password

  1. Locate the required user in User Management.
  2. Click the Change Password icon in the Actions column.
  3. Enter the new password.
  4. Click Save to update it, or Cancel to discard changes.

End of tutorial guide.
